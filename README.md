Dependencies:

## Libsodium

#### Ubuntu:
`sudo apt install libsodium-dev`

#### Fedora:
`sudo dnf install libsodium-devel`

#### Arch:
`sudo pacman -S libsodium`

---

### Strict compile flags: 
```
-std=c11
-D_DEFAULT_SOURCE
-Wall
-Wextra
-Wpedantic
-Wshadow
-Wstrict-prototypes
-Wmissing-prototypes
-Wconversion
```
